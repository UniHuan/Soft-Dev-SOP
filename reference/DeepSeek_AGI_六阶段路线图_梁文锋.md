> **核心主张：六个阶段不能跳步，全部资源只押 AGI 一条主线**
> 归档日期: 2026-08-09

## 📖 一、六阶段递进路线图

```
一阶 ──→ 二阶 ──→ 三阶 ──→ 四阶 ──→ 五阶 ──→ 六阶
语言模型  思维链   Agent   持续学习  自我迭代  具身智能
  ✅       ✅      ← 现在 →   ⏳       ⏳       ⏳
```

| 阶段 | 核心能力 | 状态 |
|------|---------|------|
| **一、语言模型** | 通过预训练获得知识和基础能力，所有后续阶段的基础 | ✅ 已完成 |
| **二、思维链（CoT）** | 长时间推理，数学/编程等明确任务超越顶尖人类。梁："去年的阶梯" | ✅ 已完成 |
| **三、Agent（智能体）** | 不只回答问题，而是调用工具、执行多步骤、完成长时任务。当前重点是 Coding Agent 和通用 Agent。梁："今年的阶梯" | 🔄 当前位置 |
| **四、持续学习** | 像人类员工在环境中持续学习，记住同事、流程、业务规则、历史决策。下一代模型必须突破的核心能力 | ⏳ 下一关卡 |
| **五、自我迭代** | AI 自己研发自己的下一个版本，探索新算法和模型架构。"AI 加速 AI 研究" | ⏳ 远期 |
| **六、具身智能** | 进入物理世界，做家务、养老等现实劳动。梁认为这是"智能的终点" | ⏳ 终点 |

## 🎯 二、关键判断

### 2.1 战略克制

> "克制是战略"

- **不做**：3D 生成、视频生成、世界模型
- **不追**：超级 App、下一个字节/腾讯
- **只押**：一条 AGI 技术主线

### 2.2 对持续学习的判断

当前模型像一个「过目即忘的天才」——每轮对话重新建立上下文，不可能支撑真正的自主工作。持续学习是当前最核心的瓶颈。

### 2.3 对具身智能的冷判断

> "现在谈具身智能太早了。"

没有持续学习和自我迭代的底子，直接搞机器人是空中楼阁。与当前人形机器人赛道的高烧形成直接对立。

### 2.4 奇点是渐进的面

不是「嘭一下突然爆发」，而是一段渐进的、可感知的加速过程。比 OpenAI "superintelligence millions of years" 的叙事更接地气。

---

## 🔗 三、内在逻辑

每一层确实建立在上一层之上：

```
语言能力 → 推理能力 → 工具使用能力 → 持续记忆能力 → 自我改进能力 → 物理操作能力
```

这个递进逻辑从第一性原理出发，不同于「什么模型刷榜就追什么」的 SOTA 追逐模式。

---

## 💡 四、感想

1. **体系感难得**：大部分 AI 公司追 SOTA 是这周刷榜追什么，没有一个从第一性原理推导的技术阶梯。这个六阶段框架不管最终对不对，逻辑链条是清晰的。

2. **战略克制更难**：在所有人都横向扩张时选择「不做」，需要做出大量取舍——不做 3D、不做视频、不做超级 App，对投资人和团队都是反人性的。

3. **当前进度**：刚走完前两层，正在爬第三层（Agent）。未来几年最关键的瓶颈不是算力参数，而是「如何让模型不遗忘」。
