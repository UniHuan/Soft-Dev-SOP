# 📈 ASO & 用户增长 SOP — 全平台覆盖

> **目标**: 提升应用商店排名、增加自然下载量、提高转化率
> **覆盖**: App Store (iOS) · Google Play (Android) · AppGallery (鸿蒙)

---

## 📊 ASO 核心要素

```
下载量 = 展示量 × 转化率

展示量 ↑ → 关键词排名 + 榜单排名 + 推荐位
转化率 ↑ → 图标 + 截图 + 评分 + 描述
```

---

## 1. 关键词优化 (100 字符空间)

### 选词策略

```
关键词金字塔:
  ├── 核心词 (1-2个): 产品核心功能  [搜索量最大, 竞争最激烈]
  ├── 功能词 (3-5个): 主要功能      [搜索量中等, 转化率高]
  └── 长尾词 (5-10个): 细分场景     [搜索量小, 竞争低, 易排名]
```

### 各平台关键词配置

| 平台 | 字段 | 限制 |
|------|------|------|
| iOS App Store | 关键词字段 | 100 字符, 逗号分隔 |
| Google Play | 短描述 + 长描述 | 80 字符 + 4000 字符 |
| 鸿蒙 AppGallery | 应用描述 | 50-8000 字符 |

### 选词工具

```
iOS: App Store Connect 关键词建议 / Sensor Tower / App Annie
Android: Google Play Console 关键词统计 / Mobile Action
鸿蒙: AGC 分析
```

## 2. 视觉优化 (提高转化率)

### 图标 A/B 测试要点

```
□ 简洁: 一个核心元素 (不要塞太多)
□ 对比: 鲜艳颜色 vs 渐变背景
□ 无文字: 图标不放文字 (太小看不清)
□ 一致性: 与应用内风格统一
```

### 截图优化

```
前 3 张截图最重要 (用户 80% 只看前 3 张):
  第 1 张: 核心功能展示 (解决什么痛点)
  第 2 张: 第二重要功能
  第 3 张: 独特卖点 (与竞品差异)
  第 4-5 张: 辅助功能

截图标题公式:
  "[动词] + [对象] + [结果]"
  例: "三秒记录想法，永不忘记" (比 "快速记录功能" 好)
```

## 3. 评分 & 评价优化

```
目标: 评分 ≥ 4.5 ★, 评价数 ≥ 100

提升策略:
□ 黄金时刻引导: 用户完成核心操作后弹窗 (非启动时)
□ 差评回复: 24 小时内公开回复 + 私信解决
□ 版本更新: 重大修复 → 主动联系差评用户 → 请求更新评价
```

## 4. 增长渠道

```
自然增长 (ASO):
  □ 关键词优化 (持续)
  □ 榜单排名 → 分类榜 Top 10 目标
  □ 编辑推荐 → 联系 Apple/Google 编辑

付费增长:
  □ Apple Search Ads (iOS)
  □ Google Ads (Android/Web)
  □ 社交媒体投放 (抖音/小红书/微博)

内容增长:
  □ 产品博客 (SEO)
  □ 使用教程视频 (B站/YouTube)
  □ 用户案例分享
```
