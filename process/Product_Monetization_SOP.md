## 🧠 变现模式决策树

```
你的产品类型?
├── 工具/效率类 → 订阅制 (Freemium → Premium)
├── 游戏类     → IAP (消耗型 + 去广告)
├── 内容/媒体类 → 订阅制 (免费试读 → 付费)
├── B2B/SaaS   → 阶梯定价 (Free → Pro → Enterprise)
├── 社交类     → 免费+广告 → IAP (虚拟物品)
└── 开发者工具  → 开源+企业版 / 免费+托管付费
```

## Phase 1: 定价策略设计 (30min)

> **[RESEARCH]** + **[GENERATE]** Claude Code 分析竞品定价并推荐

### 定价心理学

```
策略 1: 锚定效应
  Pro 版 ¥68/月
  Basic 版 ¥18/月  ← 看起来便宜多了 (实际这是目标价位)

策略 2: 中间选项效应
  Basic   ¥18/月
  Pro     ¥38/月  ← 大部分人选这个
  Enterprise ¥98/月

策略 3: 年付折扣
  ¥38/月 (月付)
  ¥298/年 = ¥24.8/月 (省 35%) ← 提升 LTV

策略 4: 终身会员
  ¥298 终身 ← 快速获取现金流, 适合早期
```

## Phase 2: 转化漏斗优化 (30min)

> **[GENERATE]** Claude Code 设计付费墙 + 试用策略

### 转化漏斗设计

```
下载 1000 人
  ↓ 60% 完成注册 (600人)
  ↓ 40% 体验核心功能 (240人)
  ↓ 15% 触发付费墙 (36人)
  ↓ 20% 完成付费 (7.2人)
═══════════════════════
转化率: 0.72% → 目标: 2%+

优化杠杆:
├── 注册转化: 社交登录 (Apple/Google) → 提升至 80%
├── 核心体验: 新手引导 (Onboarding) → 提升至 60%
├── 付费墙时机: 用户完成 5 次核心操作后 → 提升至 25%
└── 付费转化: 7 天免费试用 → 提升至 35%
```

### 付费墙 A/B 测试框架

```markdown
# 测试矩阵

| 变量 | 版本 A (对照) | 版本 B | 版本 C |
|------|-------------|--------|--------|
| 时机 | 首次打开 | 第 3 次使用后 | 核心操作×5 后 |
| 设计 | 功能对比表 | 视频演示 | 用户好评 |
| 定价 | ¥38/月 | ¥28/月 | ¥48/月 |
| 试用 | 无 | 3 天免费 | 7 天免费 |
| CTA | "开始订阅" | "免费试用 7 天" | "解锁全部功能" |

## 测试结果 (运行 2 周, 每版本 500 用户)
| 版本 | 展示 | 点击 | 付费 | 转化率 | 胜出 |
|------|------|------|------|--------|------|
| A | 500 | 120 | 18 | 3.6% | |
| B | 500 | 180 | 32 | 6.4% | 🏆 |
| C | 500 | 150 | 25 | 5.0% | |
```

## Phase 3: 留存 & 防流失 (30min)

> **[RESEARCH]** Claude Code 设计留存策略

### 留存指标

```
Day 1 留存: 40%+ (目标)
Day 7 留存: 20%+ (关键!)
Day 30 留存: 10%+

提升策略:
├── 推送通知: 个性化/时机优化 (不要骚扰)
├── 邮件营销: 每周精华/功能更新
├── Widget/小组件: 桌面常驻
├── Streak/连续打卡: 习惯养成
└── 社交分享: 用户邀请用户
```

### 流失预警 & 挽回

```markdown
# 流失用户分层

| 层级 | 定义 | 挽回策略 |
|------|------|---------|
| 活跃 | 7 天内使用 | 保持体验 |
| 风险 | 7-14 天未使用 | 推送提醒 (个性化内容) |
| 休眠 | 14-30 天未使用 | 邮件: "我们很想你" + 新功能介绍 |
| 流失 | 30+ 天未使用 | 折扣优惠 (5 折/首月免费) |

# 付费用户防流失
□ 订阅到期前 3 天: 推送提醒
□ 支付失败: 重试机制 (最多 3 次)
□ 取消订阅: 挽留页 (降价/暂停/反馈)
□ 客服响应: < 24 小时
```

## Phase 4: 扩展收入 (30min)

> **[GENERATE]** Claude Code 设计扩展收入流

### 收入多元化矩阵

```
核心收入 (70%):
└── 订阅 / IAP

扩展收入 (20%):
├── 年度会员 (提升 LTV)
├── 家庭/团队版 (客单价 ×3)
├── 增值功能 (AI/导出/主题)
└── 一次性买断 (吸引价格敏感用户)

附加收入 (10%):
├── 广告 (原生广告, 非侵入式)
├── 联盟营销 (推荐工具, 赚佣金)
└── 企业定制 (B2B 私有部署)
```

### 定价实验

```markdown
# 每月定价实验计划

| 月份 | 实验 | 变量 | 目标 |
|------|------|------|------|
| M1 | 价格测试 | ¥28 vs ¥38 | 找到最优价格点 |
| M2 | 试用期 | 3天 vs 7天 | 提升付费转化 |
| M3 | 年付折扣 | 20% vs 35% off | 提升 LTV |
| M4 | 家庭版 | 单人 vs 家庭(×2.5) | 提升客单价 |
| M5 | 地区定价 | 中国 vs 海外 | 全球变现 |
```

## 📊 变现自查清单

```
□ 有清晰的免费→付费升级路径
□ 付费墙在用户获得价值后展示 (非启动时)
□ 提供试用期 (3-7 天)
□ 年付有折扣 (≥ 30%)
□ 支持家人共享/团队版 (提升客单价)
□ 定价 ≤ 竞品平均价
□ 推送通知个性化 (非群发)
□ 流失用户有自动挽回邮件
□ 订阅失败有重试机制
□ 每月至少 1 个定价实验
□ 有变现数据看板 (每周查看)
□ 用户反馈有闭环 (反馈→修复→通知)
```
