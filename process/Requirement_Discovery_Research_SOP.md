# 🔍 需求挖掘 & 深度调研 SOP

> **适用对象**: Claude Code (AI Agent) 全自动执行 + 用户决策
> **目标**: 挖掘未来 6 个月可落地的软件产品需求，输出 3 套方案 + 价值分析
> **触发词**: "帮我挖掘软件需求" / "帮我做需求调研" / "推荐几个 App 方向"

---

## 🧠 Claude Code 技能调用

| 技能 | 说明 | 工具 |
|------|------|------|
| `[DIALOG]` | 与用户深度访谈，挖掘背景/资源/偏好 | 对话 |
| `[RESEARCH]` | 分析市场趋势、竞品、技术可行性 | 内置知识 |
| `[GENERATE]` | 生成需求方案、价值分析、对比矩阵 | `Edit`/`Write` |
| `[WRITE]` | 输出调研报告 | `Edit` |

---

## 📋 执行流程

```
Phase 1   用户画像 & 资源盘点 (15min)
Phase 2   市场趋势 & 赛道扫描 (20min)  
Phase 3   竞品分析 & 差异化定位 (20min)
Phase 4   生成 3 套需求方案 (25min)
Phase 5   深度调研 & 价值分析 (20min)
Phase 6   方案对比 & 推荐排序 (10min)
Phase 7   输出完整调研报告 (10min)
────────  总计约 2 小时
```
